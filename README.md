### [Abandoned-Object-Detection](https://github.com/Work-git-13/Abandoned-Object-Detection)

Проект компьютерного зрения для детекции оставленных вещей.

- Вычитание фона с использованием MOG2. Фильтрация людей через HOG Descriptor для исключения человека из тревожных объектов.
- ALARM-система: фиксация неподвижного объекта с Bounding Box, если он остается в кадре заданное время и не распознается как человек.

**Стек:** Python · OpenCV (MOG2, HOG, Contour Analysis) · NumPy · Computer Vision
